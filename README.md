# Gustavo Vitti — site pessoal

Esta é uma primeira versão de um site pessoal acadêmico em HTML/CSS.

## Publicar no GitHub Pages

1. Crie um repositório chamado `gustavovitti.github.io`.
2. Envie `index.html` e `style.css` para o repositório.
3. Em Settings → Pages, selecione a publicação a partir da branch principal (`main`).
4. O site ficará disponível em `https://gustavovitti.github.io`.

Os links marcados com `#` são placeholders e devem ser substituídos pelos seus endereços reais.

Posteriormente, um domínio como `gustavovitti.me` pode ser conectado ao mesmo site.
